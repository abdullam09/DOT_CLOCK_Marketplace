Prepared on September 21, 2026 for DOT CLOCK 1.0.0.

## Prepared

- Publisher metadata: ABE; stable release identifier `com.abe.dotclock`.
- Requested paid listing: US$8.99; support email `abdullam.09@gmail.com`.
- CLI-validated `.icuewidget` package targeting only `dashboard_lcd`.
- Required thumbnail and three gallery images, each 1920×960 PNG.
- Listing description, release notes, setup guide, and privacy disclosure.
- Browser verification at all eight XENEON EDGE slots, including clock boundaries, customization, error handling, translations, contrast, and offline behavior.

## Before submitting

1. Import `dot-clock.icuewidget` in iCUE and check the eight intended slot layouts on XENEON EDGE. Verify native controls, Custom Style, image placement, restart, sleep/wake, and readability. Browser tests are complete; this hardware/iCUE check is still outstanding.
2. Sign into Maker Console and select the ABE organization. The local package author is ABE; no online organization has been created or renamed by this work.
3. Create an iCUE widget product, upload the package, and paste the details from `LISTING.md`. Select paid pricing and enter USD 8.99. Complete any payment, tax, or account details requested by Maker Console.
4. Upload the thumbnail and three gallery images. Add the support email where supported. If the form requires an HTTPS support URL, supply an ABE page linking to this email; no website URL was provided or invented.
5. Review the listing and submit it for Marketplace review. This bundle has not been uploaded or published, and approval is not guaranteed by CLI validation.

The in-widget date follows the iCUE language; settings labels and supplied listing copy are English. The artwork contains genuine browser renders, not photos of a physical device. Identity icons are original dot artwork. The package includes no third-party fonts or raster libraries; it uses browser/system fonts and an ABE local-image renderer implementing documented fields.
